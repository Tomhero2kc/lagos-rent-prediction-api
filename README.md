# Lagos Rent Prediction API

I am building this project to practise using Python and machine learning to estimate annual rent for properties in Lagos.

The tool will use details such as location, property type, bedrooms and bathrooms to produce a simple rent estimate.

The dataset used in this project is created for learning, so the results should not be treated as current Lagos property prices.

## What I Plan to Build

- A small practice dataset
- A basic rent prediction model
- A simple prediction API
- Checks for missing or incorrect information
- Tests to confirm that the project works
- Clear instructions for running the project

## Current Progress

The repository is set up and the project plan is ready. My next step is to add the practice rent data.
